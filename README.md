# AI Query Validation Platform

A data platform that evaluates whether AI-generated SQL queries return accurate business results.

## Tech Stack

- SQL
- Python
- Snowflake
- dbt
- pandas
- OpenAI / Anthropic API
- Git

## Project Overview

The platform converts natural-language business questions into SQL queries and compares the generated results against validated SQL answers.

The project focuses on:

- Data modeling
- Data quality
- Semantic definitions
- Natural language to SQL generation
- Query validation
- AI evaluation
- Root-cause analysis
